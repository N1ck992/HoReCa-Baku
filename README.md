# Telegram-бот для тестирования сотрудников

Готовый к запуску бот на **aiogram 3.x** для тестирования сотрудников по
рабочим позициям (Повар, Бармен, Официант). Каждый пользователь опознаётся
по своему Telegram ID автоматически — вводить ничего вручную не нужно.

## Возможности

- Автоматическая регистрация по `/start` (Telegram ID сохраняется в базу).
- Выбор должности (легко расширяется — см. `data/seed.py`).
- Прохождение тестов по категориям, по одному вопросу за раз. Вопросы внутри
  категории идут от лёгких к сложным (поле `difficulty`: 1 → 2 → 3).
  Вопрос может показываться с картинкой (поле `image` в `data/seed.py`) —
  сейчас так сделаны все вопросы должности «Бармен».
- Подсчёт результата, процента и звёздной оценки после теста.
- **Система игровых рангов** внутри каждой должности (см. ниже) с опытом (XP)
  и прогресс-баром до следующего ранга.
- Личный рейтинг и **рейтинг заведений** (см. ниже про заведения).
- **Профиль пользователя** (кнопка 👤 Мой профиль) — единое место со статистикой,
  рангами по всем должностям, личным рейтингом, рейтингом внутри своего
  заведения (если сотрудник к нему привязан) и переходом к тестам.
- **Заведения (рестораны)**: сотрудник привязывается к заведению, просто
  отправив `/start` в Telegram-группу этого заведения. У каждого заведения
  свой менеджер со своей панелью (`/manager`) — видит результаты только
  своих сотрудников.
- **Экзамены по одноразовым кодам с таймером**: менеджер выдаёт сотруднику
  код (или сотрудник сам запрашивает его — менеджеру приходит уведомление
  с кнопкой «Выдать код»); сотрудник вводит код боту и проходит тест на
  время из самых сложных вопросов (фоновая задача сама завершает попытку,
  если время истекло); при успехе сразу переходит на следующий ранг.
- **Постоянная кнопка 🏠 Главное меню** под полем ввода — в один тап
  сбрасывает любой диалог и возвращает в базовое меню (работает и в личке,
  и в группе заведения).
- **Вакансии через Telegram-канал** (кнопка 💼 Вакансии): любой пользователь
  бота может опубликовать вакансию — бот пошагово соберёт данные и разместит
  объявление в вашем Telegram-канале. Комментарии к вакансии — это обычные
  комментарии под постом в канале (через привязанную к каналу группу
  обсуждений), бот их не хранит.
- Базовая админ-панель внутри Telegram (`/admin`): пользователи и результаты,
  журнал всех опубликованных вакансий (кто и когда разместил), создание и
  просмотр заведений.
- Все данные хранятся в SQLite и переживают перезапуск бота.

## Картинки к вопросам

Вопрос может показываться с картинкой вместо обычного текста. Для этого:

1. Положите файл картинки в `data/images/<подпапка>/<файл>.png` (подпапка —
   просто для порядка, можно назвать как угодно, например по должности).
2. В `data/seed.py` добавьте вопросу поле `"image"` с путём относительно
   `data/images/`, например:
   ```python
   {
       "text": "Какой соус подойдёт к этому блюду?",
       "options": ["Соус А", "Соус Б", "Соус В", "Соус Г"],
       "correct_index": 1,
       "image": "cook/salmon_dish.png",
   },
   ```
3. Удалите `bot.db` и запустите бота заново, чтобы вопросы пересоздались
   с картинками (см. предупреждение про пересоздание базы в разделе
   «Как обновить или добавить вопросы» ниже).

Если поле `"image"` не указано — вопрос показывается как обычно, текстом.
Сейчас с картинками оформлены **все вопросы всех трёх должностей**:
👨‍🍳 Повар (`data/images/cook/`), 🍸 Бармен (`data/images/bartender/`) и
🍽 Официант (`data/images/waiter/`).

## Система рангов

За каждый правильный ответ начисляется опыт (XP) = сложность вопроса × 10.
Опыт суммируется отдельно по каждой должности и определяет текущий ранг:

| Уровень | Повар          | Бармен         | Официант          | XP порог |
|---------|----------------|----------------|-------------------|---------|
| 1       | Стажёр повара  | Барбэк         | Стажёр            | 0       |
| 2       | Повар          | Бармен         | Официант          | 150     |
| 3       | Су-шеф         | Миксолог       | Старший официант  | 400     |
| 4       | Шеф-повар      | Бренд-бармен   | Метрдотель        | 800     |
| 5       | Бренд-шеф      | Сомелье        | Мастер сервиса    | 1500    |

Ранги, пороги XP и сами вопросы с полем `difficulty` (1/2/3) настраиваются
в `data/seed.py` — в словаре `RANKS` и в поле `"difficulty"` каждого вопроса.
Кнопка **📝 Мои тесты** внутри профиля позволяет сразу продолжить тестирование
по текущей должности; после каждого теста бот показывает, сколько XP
заработано, и поздравляет при повышении ранга.

## Заведения, менеджеры и экзамены

Бот поддерживает несколько заведений (ресторанов) одновременно. У каждого
заведения — своя Telegram-группа сотрудников и один или несколько
администраторов, которые видят результаты только своих людей.

### Как подключить заведение

Есть два способа создать заведение:

**Через админку (вручную).** `/admin` → **🏢 Рестораны** →
**➕ Добавить заведение** → укажите название и Telegram ID первого
администратора (узнать свой ID можно через @userinfobot). Заведение
создаётся сразу.

**Через заявку (самообслуживание).** Любой пользователь бота может нажать
**➕ Добавить заведение** в главном меню и указать название. Заявка
приходит вам (администратору бота) отдельным сообщением с кнопками
**✅ Одобрить** / **❌ Отклонить**. При одобрении заведение создаётся
автоматически, а первым администратором назначается тот, кто подал заявку —
ему приходит уведомление с дальнейшими шагами.

В обоих случаях дальше одинаково:

1. Бот показывает (или присылает администратору) ID заведения и просит:
   - добавить бота в Telegram-группу заведения;
   - отправить в этой группе команду `/link_restaurant <id_заведения>`.
2. После этого группа привязана. Любой сотрудник, который отправит `/start`
   **в этой группе** (не в личных сообщениях), автоматически прикрепляется
   к заведению — вводить коды или что-либо ещё не нужно. После этого
   сотрудник продолжает пользоваться ботом уже в личных сообщениях.

### Несколько администраторов на одно заведение

У заведения может быть больше одного администратора — все они видят один и
тот же список сотрудников и могут выдавать коды на экзамен. Управление
списком администраторов — **прямо в группе заведения**, командой
`/managers`: она показывает текущих администраторов с кнопкой удаления
у каждого и кнопкой **➕ Добавить администратора** (просто отправляете
Telegram ID нового человека). Добавлять и удалять может **любой** текущий
администратор — специальных прав это не требует. Единственное ограничение:
нельзя удалить последнего администратора заведения (иначе оно останется
«ничьим»).

### Назначение должностей сотрудникам

Администратор может назначить сотруднику должность (бармен, официант,
хостес — любую из существующих, включая уникальные должности своего
заведения), не дожидаясь, пока сотрудник выберет её сам. Для этого нужно
отправить **прямо в группе заведения** команду `/assign` — бот покажет
список сотрудников, при выборе сотрудника — список доступных должностей.
Кнопки видны всем в группе, но нажать их может только администратор этого
заведения (проверяется по Telegram ID).

### Инструкция для администраторов

В панели `/manager` есть кнопка **📖 Инструкция** (то же самое — команда
`/manager_help`) с кратким описанием всех возможностей: результаты
сотрудников, выдача кодов, обработка запросов на экзамен, команды `/assign`
и `/managers`. Для сотрудников аналогичная кнопка — **❓ Помощь** в главном
меню.

### Уникальные тесты под конкретное заведение

Помимо общих должностей (Повар/Бармен/Официант, видны всем), у заведения
могут быть свои уникальные должности с тестами по своему меню или
процедурам — видны только его сотрудникам.

Такие должности прописываются в `data/seed.py`, в словаре
`RESTAURANT_POSITIONS`, ключом служит **точное название заведения** (как
оно указано в /admin при создании):

```python
RESTAURANT_POSITIONS: dict[str, list[dict]] = {
    "Gazelli Cafe": [
        {
            "code": "gazelli_barista",           # уникальный код должности
            "name": "Бариста Gazelli Cafe",
            "emoji": "☕",
            "order": 1,
            "categories": [
                {
                    "code": "menu",
                    "name": "Меню кафе",
                    "emoji": "📋",
                    "order": 1,
                    "questions": [
                        {
                            "text": "Какой сироп входит в фирменный раф Gazelli?",
                            "options": ["Ванильный", "Карамельный", "Ореховый", "Кокосовый"],
                            "correct_index": 0,
                            "difficulty": 1,
                        },
                        # ... остальные вопросы в том же формате, что и в POSITIONS
                    ],
                },
            ],
        },
    ],
}
```

Формат категорий/вопросов точно такой же, как у общих должностей выше
(поддерживаются `difficulty` и `image`). Ранги для уникальной должности
задаются в том же словаре `RANKS`, по ключу `code` — если не задать, ранги
у этой должности просто не будут показываться, тест при этом всё равно
работает.

Как только:
1. в `RESTAURANT_POSITIONS` появится запись под именем заведения, и
2. заведение с точно таким названием уже создано через `/admin`,

— при следующем запуске бота (`python main.py`) должность автоматически
добавится этому заведению. Ничего пересоздавать вручную не нужно, повторные
запуски безопасны — дублей не будет. Если структура базы менялась (новые
таблицы/поля), как обычно перед запуском стоит удалить `bot.db`.

Должность видна **только** сотрудникам этого заведения — остальные
пользователи бота (включая сотрудников других заведений) её не увидят.

### Панель менеджера — `/manager`

Менеджер, назначенный на заведение, пишет боту `/manager` в личных
сообщениях и видит:

- **👥 Результаты сотрудников** — список всех, кто прикреплён к его
  заведению, с должностью, количеством тестов и средним результатом.
- **🎓 Выдать код на экзамен** — выбирает должность, бот генерирует
  одноразовый 6-значный код (например `AHLNFK`). Код нужно передать
  сотруднику любым удобным способом (лично, в чате группы и т.д.) —
  бот сам никому его не пересылает.

### Экзамен по коду — сторона сотрудника

Кнопка **🎓 Сдать экзамен** в главном меню видна только тем, кто уже
прикреплён к какому-то заведению (то есть хотя бы раз отправил `/start` в
группе заведения) — у остальных пользователей бота её нет.

На экране экзамена — два варианта:
- **Ввести код** — если код уже есть, просто отправляете его текстом.
- **📩 Запросить код у менеджера** — выбираете должность, затем **выбираете
  конкретного администратора** заведения из списка (если их несколько) —
  уведомление с кнопками **✅ Выдать код** / **❌ Отклонить** приходит
  только этому администратору, остальные его не видят. При одобрении бот
  сам генерирует код и присылает его сотруднику в этот же чат —
  копировать/пересылать код вручную не нужно.

После получения кода бот запускает тест на время (по умолчанию 3 минуты) по
самым сложным вопросам выбранной должности — по одному вопросу из каждой
категории, с оставшимся временем в заголовке каждого вопроса. Код
одноразовый: помечается использованным сразу при старте попытки.

Если участник не отвечает достаточно быстро сам, отдельная фоновая задача
принудительно завершает попытку по истечении времени и присылает сообщение
«⏰ Время вышло» — экзамен не «зависает», даже если сотрудник просто закрыл
чат и забыл про него.

Если сотрудник отвечает правильно на 75% вопросов и укладывается по времени —
экзамен считается сданным, и сотрудник **сразу** переходит на следующий ранг
по этой должности (начисляется ровно столько бонусного опыта, сколько нужно
для перехода на порог следующего ранга — см. `PASS_THRESHOLD` в
`handlers/exams.py`).

### История экзаменов в панели администратора

В `/manager` → **👥 Результаты сотрудников** список сотрудников теперь
кликабельный: нажав на сотрудника, администратор видит не только текущую
статистику тестов, но и полную историю экзаменов — по каждой попытке:
должность, баллы (например «4/4»), статус (✅ Сдан / ❌ Не сдан), **какой
именно администратор выдал код** на эту попытку (то есть допустил до
экзамена) и дата. Это относится ко всем экзаменам, независимо от того, был
код выдан вручную через «🎓 Выдать код» или через одобрение запроса
сотрудника.

### Рейтинг заведений и личный рейтинг

Главное меню показывает **🏢 Рейтинг заведений** — заведения сравниваются по
среднему проценту правильных ответов их сотрудников. Это НЕ рейтинг
отдельных людей. Личный рейтинг остался в профиле (кнопка 👤 Мой профиль):
там показывается место среди вообще всех пользователей бота, а если
сотрудник прикреплён к заведению — ещё и отдельная строка с местом именно
внутри своего заведения.

## Кнопка «Главное меню» и возврат в меню

Под полем ввода у бота есть постоянная кнопка **🏠 Главное меню** — она
всегда на месте, независимо от того, в каком экране/диалоге сейчас
находится пользователь. Нажатие на неё делает ровно то же самое, что и
команда `/start`: сбрасывает любой незавершённый диалог (ввод вакансии, код
экзамена и т.д.) и показывает базовое меню. Она появляется автоматически
после первого `/start` — и в личных сообщениях, и в группе заведения (там
её нажатие повторно подтверждает привязку к заведению).

Помимо этого, все админ- и менеджерские действия (создание заведения,
выдача кода на экзамен, публикация вакансии и т.д.) теперь заканчиваются
показом соответствующего меню, а не «глухим» финальным сообщением — так
не нужно вручную писать `/start` или `/admin`/`/manager` заново, чтобы
продолжить работу.

## Вакансии

Раздел **💼 Вакансии** предлагает две кнопки:

- **🔍 Поиск вакансии** — прямая ссылка на ваш Telegram-канал, где публикуются
  все объявления (и где под ними будут обычные комментарии Telegram, если у
  канала подключена группа обсуждений).
- **📤 Опубликовать вакансию** — доступно любому пользователю бота. Бот
  пошагово спросит название, описание, зарплату и локацию (последние два
  можно пропустить, отправив `-`), затем сам опубликует готовое объявление в
  канал.

### Настройка канала вакансий

1. Создайте публичный Telegram-канал (или используйте существующий).
2. Добавьте вашего бота в канал как администратора с правом **публикации
   сообщений**.
3. (Опционально) Подключите к каналу группу обсуждений — тогда под постами
   будут появляться комментарии прямо в Telegram, без участия бота.
4. Впишите username канала в `.env`:
   ```
   VACANCIES_CHANNEL=@your_channel_username
   ```

Пока `VACANCIES_CHANNEL` не задан, кнопка «Поиск вакансии» не показывается,
а «Опубликовать вакансию» отвечает, что канал не настроен.

Через `/admin` → **📋 Опубликованные вакансии** администратор видит журнал
всех вакансий, которые публиковали пользователи бота (кто и когда), и может
удалить запись из этого журнала (само сообщение в канале при этом нужно
удалить вручную средствами Telegram).

│   ├── models.py             # таблицы SQLAlchemy (+ RestaurantManager, ExamRequest)
│   └── crud.py                # все запросы к базе (+ рестораны/рейтинг/экзамены)

│   ├── start.py               # /start (в т.ч. привязка к заведению из группы)

│   ├── restaurant_requests.py     # ➕ Добавить заведение (заявка + одобрение админом)

│   ├── vacancies.py                  # 💼 публикация вакансий в Telegram-канал (FSM)
│   ├── help.py                        # ❓ Помощь — туториал для сотрудников
│   └── admin.py                     # админ-панель: пользователи, вакансии, заведения

│   └── keyboards.py            # инлайн-клавиатуры
├── services/
│   └── rating.py                 # звёзды, ранги, отображаемое имя

**Логика бота полностью отделена от контента тестов.** Чтобы изменить,
добавить или удалить вопросы, категории или должности — редактируйте
только `data/seed.py`. Если база данных уже создана и заполнена, `seed.py`
не перезаписывает существующие данные автоматически (см. раздел
«Как обновить вопросы» ниже).

## База данных

SQLite (файл `bot.db`, создаётся автоматически при первом запуске).
Используется асинхронный SQLAlchemy 2.0 ORM, поэтому переход на PostgreSQL
в будущем — это всего лишь замена строки `DATABASE_URL` в `.env` (например,
на `postgresql+asyncpg://user:password@host:5432/dbname`) и установка
драйвера `asyncpg`. Код моделей и запросов менять не придётся.

Таблицы: `users`, `positions`, `categories`, `questions`, `answer_options`,
`test_results`, `user_answers`.

## Установка и запуск

### 1. Получите токен бота

Напишите в Telegram боту **@BotFather**, создайте нового бота командой
`/newbot` и скопируйте выданный токен.

### 2. Узнайте свой Telegram ID (для админки)

Напишите боту **@userinfobot** — он пришлёт ваш числовой ID.

### 3. Установите Python-зависимости

```bash
cd bot
python3 -m venv venv
source venv/bin/activate      # на Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 4. Настройте .env

```bash
cp .env.example .env
```

Откройте `.env` и укажите:
```
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_ID=ваш_telegram_id
VACANCIES_CHANNEL=@username_вашего_канала_вакансий
```
(канал можно настроить позже — без него всё остальное в боте работает как
обычно, недоступна только публикация вакансий; см. раздел «Вакансии» ниже)

### 5. Запустите бота

```bash
python main.py
```

При первом запуске автоматически создастся файл `bot.db` и заполнится
начальными данными (3 должности × 4 категории × 5 вопросов).

## Как протестировать сценарий из ТЗ

1. Откройте бота в Telegram с одного аккаунта, нажмите **/start**.
2. Нажмите **👔 Выбрать должность** → **🍽 Официант**.
3. Выберите категорию, например **🧾 Работа с заказами**.
4. Ответьте на 5 вопросов — после каждого ответа бот покажет ✅/❌ и
   перейдёт к следующему вопросу.
5. В конце увидите результат (например, «4/5, 80%, ⭐⭐⭐⭐☆»).
6. Откройте **👤 Мой профиль** — там же увидите свой ранг, статистику и место в рейтинге.
7. Повторите шаги 1–4 со **второго** Telegram-аккаунта (или попросите
   коллегу/используйте второй телефон).
8. Откройте **🏆 Таблица лидеров** — там появятся оба пользователя с их
   процентами, отсортированные по результату.
9. Остановите бота (`Ctrl+C`) и запустите заново (`python main.py`) —
   все результаты и рейтинг сохранятся, так как они лежат в `bot.db`.
10. Напишите `/admin` со своего аккаунта (указанного как `ADMIN_ID`) —
    откроется список пользователей и их статистика.

## Как обновить или добавить вопросы

Все вопросы, варианты ответов, категории и должности находятся в одном
месте — `data/seed.py`, в виде обычной Python-структуры (списка словарей).
Ничего в логике бота менять не нужно.

Так как функция `seed_data()` заполняет базу только один раз (при пустой
таблице должностей), для применения изменений в уже существующей базе:

- **Проще всего на этапе разработки:** удалите файл `bot.db` и запустите
  бота заново — база создастся и заполнится актуальными данными из
  `seed.py`.
- **Для продакшена (не терять результаты сотрудников):** добавляйте новые
  должности/категории/вопросы через SQL или через `database/crud.py`,
  не удаляя базу — либо расширяйте `seed_data()` дополнительной логикой
  «добавить, если не существует» для конкретных новых записей.

## Расширение под администратора

В `config.py` уже заложен `ADMIN_ID`. Команда `/admin` и колбэк
`admin:users` в `handlers/admin.py` — это основа, к которой легко
добавить новые разделы (редактирование вопросов, должностей и т.д.),
не трогая остальной код бота.
