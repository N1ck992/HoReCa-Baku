# Картинки к вопросам тестов

Сюда кладутся файлы изображений, на которые ссылаются вопросы в
`data/seed.py` через поле `"image": "имя-файла.jpg"`.

Сайт покажет картинку над текстом вопроса, аккуратно обрезанной под
единый размер (соотношение сторон 4:3) — независимо от исходного
размера и формы фотографии.

Рекомендации по самим файлам:
- Формат: JPG или PNG
- Желательно заранее обрезать под пропорцию, близкую к 4:3 (например,
  1200×900) — тогда обрезка сайтом будет минимальной
- Имя файла — латиницей, без пробелов (например, `caesar-salad.jpg`)
