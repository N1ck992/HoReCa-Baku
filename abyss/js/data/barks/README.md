# Реплики над головой (barks)

Короткие мысли, замечания и обращения персонажей друг к другу — всплывают над головой во время игры.
**У каждого персонажа — свой файл.** Править тексты можно прямо здесь; ID и ключи не трогать.

| Файл | Кто |
|---|---|
| `CHAR-001.js` | Марк |
| `CHAR-002.js` | Спутница |
| `CHAR-003.js` | Доктор Хейл |
| `mutant.js` | Мутанты (`ENEMY-001`, `004`, `005`, `006`) — обрывки человеческой речи |
| `ENEMY-002.js` | Преследователь |

## Формат строки

```js
{ text: 'Что сказать', think: true, reply: { by: 'CHAR-002', text: 'Ответ' }, once: true, needs: 'CHAR-002', after: 'EVENT-006' }
```

- `think: true` — мысль (курсив в скобках, слышит только игрок); без него — сказано вслух.
- `reply` — ответ другого персонажа через пару секунд (если он рядом).
- `once: true` — сказать только один раз за игру.
- `needs` — только если этот персонаж рядом; `after` — только после сюжетного события.

## Когда звучат (ключи)

| Ключ | Когда |
|---|---|
| `enter:ROOM-XXX` | первый раз зашли в помещение |
| `idle`, `idle:ROOM-XXX` | долго тихо — мысль или разговор |
| `alert`, `alert:ENEMY-XXX` | противник заметил группу |
| `kill` | противник убит |
| `hurt` | здоровье ниже 40% |
| `heal` | аура дротикового пистолета лечит |
| `lead` | персонаж стал ведущим |
| `pickup:ITEM-XXX` | подобрал вещь |
| `log:LOG-XXX` | прочитал находку |
| `appear:ENEMY-002` | появился преследователь |
