# Оружие — папка категории

Здесь лежат файлы оружия: исходники звуков, картинки, дизайн. Параметры боя и привязка звуков — в **`js/data/weapons.js`**
(единый реестр `AB.WEAPONS`). Подробности полей — в шапке этого файла.

## Структура

```
assets/weapons/
  README.md              — этот файл
  <имя оружия>/
    source/              — исходные файлы звуков и картинок «как получили» (не подключаются в игру напрямую)
    design/              — рисунки оружия: иконка, в руке, отдельная картинка (когда появятся)
```

Готовые к игре звуки лежат в `assets/audio/` (их читает звуковой модуль) и перечислены в `assets/audio/sounds.json`.

## Как добавить оружие

1. Предмет — в `js/data/items.js` (`category: 'weapon'`, поле `weapon: {}` — пустое, его наполнит реестр).
2. Запись в `js/data/weapons.js`: `params` (урон, дальность px, перезарядка, перегрев, аура…), `sound.shot` / `sound.hit`
   (имя группы из `sounds.json`; `null` — звук по умолчанию), `design` (иконка, как рисуется в руке, статус).
3. Звук: положить исходник в `<оружие>/source/`, собрать `assets/audio/<имя>.mp3` (моно, 44,1 кГц, без тишины в начале,
   громкость выровнена), добавить группу в `sounds.json` и громкость в `iso-audio.js` (`RULES.vol`).
4. Рисунок: положить в `<оружие>/design/`, подключить через `assets.manifest.js` (иконка) или в `renderer.js drawWeapon` (в руке).
5. Строка в `docs/GDD-CHANGES.md`.
