# PROJECT ABYSS для Android (дополнение №110)

Приложение — оболочка WebView: игра и все её файлы лежат внутри APK, интернет не нужен.

## Сборка APK
```
export ANDROID_SDK=/путь/к/sdk        # нужны platforms;android-34 и build-tools;34.0.0, Java (javac)
export ABYSS_KS=/путь/к/abyss.keystore ABYSS_KS_PASS=…   # ключ подписи — хранится у автора, не в репозитории
bash tools/build_apk.sh 45            # → dist/project-abyss-v45.apk и android/releases/v45.json
```
**Ключ подписи не терять:** обновить установленное приложение можно только APK с тем же ключом
(иначе — удалить старое, и сохранения пропадут). Ключ в репозиторий не кладётся (`.gitignore`).

## Патч (обновление без переустановки)
```
python3 tools/make_patch.py 45 46     # основа — версия установленного APK, новая версия
                                      # → dist/project-abyss-patch-v46.zip (только изменённые файлы)
```
В игре: «Патч» → «Выбрать файл патча» → выбрать zip. Патч накопительный (всё, что изменилось с версии APK),
достаточно последнего. «Сбросить патч» — вернуть версию из APK. Патчу ключ подписи не нужен.

Код Java — без лямбд и со **статическими** вложенными классами: d8 из build-tools 34 не понимает
конструкторы вложенных классов, которые записывает javac 21.
