# Реестр ID — ABYSS: LOST SIGNAL

Все ID постоянные: после утверждения их не меняют (GDD §2.7).
Источник правды — файлы в `js/data/`; этот документ дублирует их для чтения.

## Ждут вашего подтверждения

| ID | Что это | Почему добавлено |
|---|---|---|
| `ROOM-TMP-001` | Первый коридор | Этап 3 требует «первый коридор», но в списке помещений GDD §6 его нет. Нужен постоянный ID (например, `ROOM-011`) или указание, частью какого помещения он является |
| Восточная дверь `ROOM-TMP-001` | Дверь в конце коридора | Куда она ведёт, в GDD не указано. Пока обесточена |
| `ANIM-CHAR001-05` | Ожидание (дыхание) | Герою нужна анимация, когда он стоит на месте |
| `ANIM-CHAR001-06` | Выход из криокапсулы | Нужна для EVENT-001 «Пробуждение» |
| Имя `CHAR-001` | Сейчас «Главный герой» | Имя в GDD не задано |
