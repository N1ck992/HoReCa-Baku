# Реестр ID — ABYSS: LOST SIGNAL

Все ID постоянные: после утверждения их не меняют (GDD §2.7).
Источник правды — файлы в `js/data/`; этот документ дублирует их для чтения.

## Открытые вопросы

| Что | Сейчас |
|---|---|
| Куда ведёт восточная дверь `ROOM-011` | Дверь обесточена, направление не задано |
| Имя `CHAR-001` | «Главный герой» |
| Расстановка предметов по помещениям | Предложена мной (см. ниже), можно менять |

## Утверждено

- `ROOM-011` — первый коридор (раньше временный `ROOM-TMP-001`; старые сохранения переносятся автоматически).
- `ANIM-CHAR001-05` — ожидание, `ANIM-CHAR001-06` — выход из криокапсулы.
