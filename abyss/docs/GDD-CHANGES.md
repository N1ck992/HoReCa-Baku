## Открытые вопросы

- **Имя спутницы `CHAR-002`.** Сейчас заглушка «Спутница». По канону она представляется коллегой Марка.
- **Внешность спутницы.** Нужна для промпта графики (фигура в полный рост по CHARACTER-ART-SPEC).
- **Реплики `DIALOG-001`** — черновик, ждёт правки (см. js/data/dialogs.js).
- **Стопки в рюкзаке.** Сейчас одинаковые вещи складываются; если нужно строго по одной — скажите.
- **Медик `CHAR-003`:** имя, внешность, первые реплики.
- **Иллюминатор `ROOM-008`:** сейчас — дно, лучи прожекторов, «морской снег» и проходящий левиафан. Поправьте, если видите иначе.
- **Реплики `DIALOG-002…004`** (врач, иллюминатор, экзокостюм) — черновики.
- **Колосс `ENEMY-003`:** имя, внешность (сейчас — увеличенный мутант с другой окраской).
- **Экзокостюм `EQUIP-005`:** название модели, внешний вид для промпта графики.
- **Графика новых помещений** `ROOM-006, 007, 009, 010` — пока заглушки.
